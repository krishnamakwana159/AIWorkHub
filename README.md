# AIWorkHub

AIWorkHub is an AI-powered task and knowledge management platform planned for a .NET backend, React frontend, and OpenAI integration.

This repository currently contains the production repository scaffold only. The .NET solution and React application have intentionally not been created yet.

## Repository Structure

```text
AIWorkHub/
├── backend/              # Future .NET backend source
├── frontend/             # Future React frontend source
├── docs/                 # Architecture, setup, roadmap, and ADR documentation
├── scripts/              # Future automation and developer scripts
├── .github/workflows/    # Future CI/CD workflow definitions
└── .vscode/              # Workspace editor configuration
```
